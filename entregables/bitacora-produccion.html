Bitácora de producción del portafolio web

Documenta el paso a paso conceptual y técnico seguido para la resolución y creación de cada producto académico de este portafolio, los desafíos encontrados y cómo se solucionaron.

01 · Planeación y estructura

  • Desafío: Definir qué contenido incluir y cómo organizarlo para cumplir la consigna del examen.
  • Solución: Estructurar el sitio en cuatro bloques alineados con la consigna: presentación personal, galería de actividades, derechos de autor y referencias bibliográficas.
  • Herramientas: boceto en papel, editor de código (VS Code), navegador web.

02 · Desarrollo del sitio

  • Desafío: Hacer la página adaptable (computador y celular) y accesible.
  • Solución: CSS con variables, media queries, menú desplegable accesible con ARIA y salto al contenido.
  • Herramientas: HTML5 semántico, CSS3, JavaScript nativo.

03 · Contenido y actividades

  • Desafío: Redactar la presentación personal, la finalidad de la página y el resumen del semestre sin repetir información.
  • Solución: Separar en tres bloques claros: perfil del estudiante, propósito del sitio y recorrido del curso.
  • Herramientas: procesador de textos para borradores, revisión ortográfica.

04 · Derechos de autor y referencias

  • Desafío: Asegurar que todo contenido visual cumpla con normas de propiedad intelectual.
  • Solución: Usar solo ilustraciones propias o de fuentes con licencia libre, incluir atribución y enlaces a las fuentes originales.
  • Herramientas: bancos de imágenes con licencia libre, guía APA 7.ª edición.

05 · Pruebas y publicación

  • Desafío: Verificar que el sitio se vea bien en diferentes pantallas.
  • Solución: Pruebas en computador y celular, validación de enlaces y contraste de colores.
  • Herramientas: DevTools del navegador, GitHub Pages (opcional para publicación).

Nota: Para realizar la entrega del examen, el estudiante debe asistir a clase de manera presencial. De lo contrario, la entrega no será válida.
